# डोगरी गीत

A single-page Jammu / Dogri music radio — full-bleed Duggar hills scene, floating player, and a curated YouTube queue (same pattern as [Koshur Radio](https://github.com/dkoul/koshur-radio)).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Tracks

Hand-curated IDs live in `src/data/tracks.ts`. Filter chips: **Folk** / **Matador**.

Matador pulls from [Jammu matador vol 1](https://music.youtube.com/playlist?list=PLaFMODhciZxbIke0bpzFLaK-BQXyFL1Ua).
